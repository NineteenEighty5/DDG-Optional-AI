# DDG Optional AI
A Firefox extension to make AI results optional on DuckDuckGo, by default you will get no AI results

## Install it
https://addons.mozilla.org/en-GB/firefox/addon/ddg-optional-ai/

## Use it
Add one question mark (?) to the end of your DuckDuckGo search to see AI-enhanced results instead. Add two question marks (??) to open Duck.ai chat with your question already typed in.

Kudos for Kagi for the original idea, this just makes the functionality available to everyone.
